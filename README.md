# 色塊人宇宙都市 Blockman Universe City

自訂或手繪色塊人角色，走進宇宙都市的各棟建築，每棟建築都是一款多人連線遊戲。（Node.js + Socket.io）

## 都市地圖
城市重新規劃中：目前中央廣場只保留噴水池、長椅、路燈與樹木，沒有遊戲建築。
新的建築與入口會在 `server/maps.js` 的 `plazaMap()` 加上。

## 你畫我猜（遊戲程式保留，暫時沒有入口）
- 走進發光的入口 → 大廳：🏠 建立公開房間／🎲 隨機加入／🔒 私人房間（4 碼代碼，不會出現在隨機配對）
- 房主可設定人數上限（2–8）、作畫時間、輪數；其他人按「準備」，至少 2 人且全員準備後開始
- 系統從題庫（動物、食物、生活用品、交通工具、校園事物，約 180 題）隨機出題，同一局不重複，題目只有畫圖者看得到
- 畫圖工具：14 色畫筆、4 種粗細、橡皮擦、復原（Ctrl+Z）、清空
- 猜對時顯示「某某答對了！」並隱藏答案；已答對的人說話只有畫圖者和其他答對者看得到
- 提示：作畫 40% 時公布類別、70% 時揭曉一個字；猜得接近會私下提示「很接近了」
- 計分：答對 50–100 分（越快越高）＋前三名加成；畫圖者每有一人答對 +25，全員答對再 +20
- 全員答對或時間到 → 公布答案與本回合得分 → 自動換下一位；所有輪次結束顯示排行榜

## 程式結構
- `server.js`：連線、區域切換（廣場 ↔ 建築）、主迴圈
- `server/world.js`：可走動場景（移動、碰撞、入口偵測）；`server/maps.js`：廣場地圖
- `server/drawguess.js`、`server/words.js`：你畫我猜的房間、流程、計分與題庫
- `public/game.js`：2.5D 場景渲染；`public/props.js`：建築與擺設；`public/studio.js`：畫室場景
- `public/dg.js`：你畫我猜介面與畫板；`public/app.js`：畫面切換

## 玩法
1. 在角色編輯器選擇「色塊模式」設定頭、身體、腳的顏色，或用「手繪模式」畫出自己的角色
2. 輸入暱稱，按「進入宇宙都市」，出現在中央廣場
3. 方向鍵 / WASD（手機用觸控方向鍵）在廣場上移動

## 畫面
- 2.5D 俯視角：物件有頂面、正面與投影，依前後深度排序
- 每回合隨機生成地圖（磚牆、石頭、闊葉樹、松樹）
- 高解析度畫布，支援 Retina / 手機高 DPI
- 被樹擋住時樹冠會變透明，被牆擋住時仍看得到自己的身影

## 移動同步
- 客戶端預測：按鍵後角色立即在本機移動，不必等伺服器來回
- 伺服器校正：伺服器確認後重播未確認的指令，誤差會在數十毫秒內平滑消化
- 其他玩家：延後 100ms 顯示並在兩個快照之間插值，封包晚到時依速度短暫外推
- 物理：固定 1/60 秒步長，有加速與減速，伺服器和瀏覽器共用 `public/shared.js`
- 防作弊：伺服器依實際時間發放步數額度，無法用加速外掛
- 動畫：轉身翻面、跑步晃動、前傾都會平滑過渡，腳步會揚起灰塵
- 畫面：遊戲畫面依視窗大小放到最大；建築、樹木、角色的預繪解析度會跟著畫面大小自動提高
- 雙層畫布：地面與建築畫在底層（只畫一次），上層每格只畫角色、星星與入口光圈，以及擋在角色前面的物件
- 其他玩家的顯示延遲依網路抖動自動調整（70～300ms），伺服器每秒廣播 40 次
- 效能：長時間低於 30fps 才自動降一次解析度；排行榜只在有變動時更新
