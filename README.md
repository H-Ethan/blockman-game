# 色塊人城市 Blockman City

一座持續擴充的多人桌遊城市。玩家建立自己的色塊人，在 2.5D 等角城市裡自由走動，走進桌遊建築就能開房、加入房間，和其他玩家一起玩。
第一棟可完整遊玩的建築是 **「誰是臥底」**。（Node.js + Express + Socket.io，前端純 Canvas，不需要建置工具）

## 啟動方式
```bash
npm install
npm start            # http://localhost:3000
```
需要 Node.js 18 以上。部署到 Render：Build Command `npm install`、Start Command `npm start`。

## 多人測試方式
- **手動**：用兩個以上「獨立的瀏覽器工作階段」開同一個網址（例如一般視窗＋無痕視窗，或不同瀏覽器、手機），各自建立角色，走進「誰是臥底」門口 → 一人建立房間，其他人用「瀏覽公開房間／隨機加入／輸入房間代碼」加入 → 準備 → 開始。至少 4 人才能開始。
- **自動**：`npm test`，會啟動一台計時縮短 20 倍的測試伺服器，用多個獨立連線跑完 63 項整合測試（4 人局、含白板局、平票 PK、全員棄權、超時、斷線恢復與離席、密碼房、隨機配對、詞語不外洩）。

## 玩法流程
建立色塊人 → 進入城市 → 自由移動 → 走進「誰是臥底」門口（自動進入大廳）→ 建立或加入房間 → 準備 → 查看詞語 → 輪流描述 → 自由討論 → 投票（平票 PK）→ 淘汰／白板猜詞 → 結算 → 再玩一局或返回城市

## 已完成項目
**城市與角色**
- 2.5D 等角城市街區：道路、斑馬線、人行道、中央廣場與噴水池、植栽、路燈、長椅、指示牌、公告欄；施工中工地與建築預定地（只有圍籬，沒有無作用的入口）
- 「誰是臥底」偵探社建築：屋頂巨大放大鏡、偵探帽、霓虹問號、招牌、條紋雨遮、發光入口與接近提示
- 色塊人：立體的頭、身體、手腳與表情；可設定暱稱、身體主色、配色、膚色、髮色、6 種表情、帽子（含偵探帽）、眼鏡；即時預覽（可旋轉、走路預覽）；設定保存在本機，下次沿用，城市中可隨時修改
- 暱稱長度限制（1～10 字）、不當字詞與保留字過濾；聊天遮蔽不當字詞、長度與頻率限制，所有文字一律以純文字顯示
- 頭頂名牌與對話泡泡（依長度決定顯示時間、限制行數、多人發言自動錯開、不同類型不同樣式）

**移動**
- WASD／方向鍵，依畫面方向移動，斜走與直走一樣快；聊天輸入時暫停移動鍵
- 手機與平板：虛擬搖桿（不遮住入口提示與按鈕）
- 加速／減速、平滑轉向、待機呼吸、走路擺動；建築與家具碰撞；角色與物件前後遮擋（被建築擋住時仍看得到自己的淡淡身影）
- 客戶端預測＋伺服器校正、其他玩家依網路抖動調整的插值；入口感應區有冷卻與「離開一段距離才重新觸發」的緩衝，離開建築會出現在門外安全位置

**大廳與房間**（通用房間系統，之後的建築可直接沿用）
- 大廳四個入口：建立房間、瀏覽公開房間、隨機加入、輸入房間代碼
- 房主設定：房間名稱、公開／密碼房、密碼、人數上限 4～12、白板、描述／討論／投票時間、題庫分類與難度；等待中可再修改
- 公開列表顯示名稱、人數、上限、房主與狀態；隨機加入只配對未開始、有空位的公開房；沒有房間時提示建立
- 密碼房不出現在列表與隨機配對；代碼與密碼是不同資訊；密碼只在伺服器以 scrypt 驗證，不傳給任何前端；密碼嘗試有次數限制
- 2.5D 遊戲室，角色圍繞中央圓桌就座；顯示房主、準備、連線狀態、房間代碼（可複製）與設定
- 至少 4 人且所有非房主玩家準備後才能開始；開始後鎖定名單，不能中途加入

**誰是臥底規則**（全部由伺服器判定，畫面上的規則說明與程式使用同一份資料）
- 依人數表分配平民／臥底／白板；每局重新抽題與分配身分
- 89 組繁體中文題庫（食物、動物、生活用品、交通工具、校園、場所；分簡單／普通／困難），同一房間題庫用完前不重複；題庫只在伺服器
- 每位玩家只收到自己的詞語（整合測試會檢查前端收到的所有資料）；白板知道自己是白板
- 查看詞語：按住查看或顯示／隱藏，全員確認或倒數結束後開始
- 輪流描述：第一輪隨機起始（白板不排第一），之後輪替起始座位、跳過淘汰者；只有當前玩家能送出；超時記「本輪未描述」；直接包含自己詞語會被擋下並提示
- 自由討論：存活玩家聊天（不能直接說出自己的詞語），全員同意可提前投票
- 投票：不能投自己或淘汰者、截止前可改票、結束前不公開票數、全員投完提前結算、未投視為棄權、全員棄權無人淘汰
- 平票 PK：平票者各補充一句，再從平票者中重投；再次平票本輪無人淘汰（不會無限 PK）
- 淘汰公開身分（詞語保留到結算），角色變灰；淘汰者可觀戰並使用存活玩家看不到的觀戰頻道
- 白板被投出後 15 秒猜一次平民詞：猜中單獨獲勝；猜測內容只有白板自己看得到
- 勝負：① 白板猜中 → 白板獨贏 ② 臥底與白板全滅 → 平民勝 ③ 存活臥底＋白板 ≥ 存活平民 → 非平民陣營勝 ④ 其餘繼續
- 結算：獲勝陣營、所有身分與詞語、淘汰順序、各輪描述與投票；再玩一局（保留設定、重新準備）或返回城市

**紀錄、連線與異常處理**
- 右側紀錄：正式描述、聊天、投票結果、系統事件，含時間與類型；可切換「全部／描述／系統」；往上閱讀時不會被拉回底部，有「新訊息」提示；手機版為可展開的面板
- 重新整理或短暫斷線：恢復原角色、座位、本人詞語與紀錄；斷線保留席位 60 秒，期間遊戲照常計時；逾時視為離席，遊戲中棄權淘汰（不觸發白板猜詞）並重新檢查勝負
- 房主離開或斷線自動移交；重複送出開始、描述、投票不會重複處理；同一角色在另一個分頁開啟時舊分頁會提示
- 載入中、連線中斷、密碼錯誤、房間已滿、遊戲已開始等狀態都有明確提示

**效能**
- 渲染（每格）與網路同步（城市每秒 25 次）分離；城市地面切成區塊、建築預先繪製成與螢幕同解析度的圖片直接貼上；名牌與泡泡文字預先排版
- 畫質三段（高／標準／省電），長時間低於約 38 fps 會自動降一級

## 實際限制
- 房間與連線狀態存在伺服器記憶體中：伺服器重啟（例如重新部署、Render 免費方案休眠後喚醒）會清空所有房間；目前只支援單一伺服器實例
- 描述的語意違規（拆字、拼音、諧音）系統無法完全辨識，只會擋下直接包含自己詞語的描述，其餘靠玩家自律
- 不當字詞過濾是固定詞表，無法涵蓋所有變體
- 效能數據來自無顯示卡的軟體繪圖環境；實體電腦與手機通常更快，但尚未在實機上量測
- 角色改為幾何色塊造型（頭身手腳＋表情＋配件），舊版的像素手繪模式已移除
- 舊版「你畫我猜」程式已移除（保留在 git 歷史中），之後會改用新的房間系統重新加入

## 程式結構
```
server.js                         連線、工作階段、區域切換、主迴圈
server/core/city.js               城市移動（伺服器權威）、碰撞、入口緩衝、城市聊天
server/core/rooms.js              通用房間系統（列表、配對、密碼、座位、準備、房主移交、紀錄頻道）
server/core/filter.js、ratelimit.js 文字安全與頻率限制
server/games/undercover/          誰是臥底規則（game.js）與題庫（words.js，只在伺服器）
public/js/shared/                 前後端共用：移動物理、城市地圖、誰是臥底規則表
public/js/iso.js、avatar.js        等角繪圖工具、色塊人
public/js/props.js、city.js        城市美術與城市場景
public/js/roomscene.js             大廳與遊戲室場景
public/js/ui-*.js、app.js          介面與連線
test/server-test.js               多人整合測試
```
新增桌遊建築：在 `citymap.js` 加建築與入口、在 `server/games/` 寫新的規則類別（提供 `validateSettings`、`start`、`action`、`tick`、`viewFor`、`onGone`、`chatChannel`），再用 `RoomManager` 接上即可。
